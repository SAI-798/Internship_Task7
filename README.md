## ⚡ Learning Simple and Readable Python

My goal is to understand the logic first and then use Python's built-in features when they make the solution clearer.

| Task | Python technique |
|---|---|
| Find unique characters | `set(s)` |
| Reverse a string | `s[::-1]` |
| Count character occurrences | `Counter(s)` |
| Find common elements | `set(a) & set(b)` |
| Find symmetric difference | `set(a) ^ set(b)` |
| Calculate the total | `sum(numbers)` |
| Find the length | `len(s)` |
| Convert input into integers | `list(map(int, input().split()))` |
| Combine characters into a string | `"".join(chars)` |
| Check whether a character is uppercase | `ch.isupper()` |

💡 **My learning principle:** Understand the basic logic before using shortcuts. Writing code that I can explain is more important than simply memorizing a solution.
